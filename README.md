# superstore-sales-analysis-powerbi
Superstore dataset using Power BI for Sales

## Project Overview
This project analyzes Superstore sales data using Power BI to understand sales performance and profitability.

## Business Questions
- Which categories and sub-categories generate the highest sales?
- Which regions are most profitable?
- How do sales and profit change over time?

## Dashboard
An interactive Power BI dashboard was built to analyze sales, profit, and quantity.

## Tools Used
- Power BI
- Excel
